# I Can Handle This

**I Can Handle This** is an integrated skill for creating complete presentations. Instead of applying one fixed template, it adapts the narrative structure, visual style, layout, icons, charts, and animation to the topic and audience.

It supports editable PowerPoint (`.pptx`) decks and, when requested, offline HTML presentations. It can be used for teaching materials, reports, proposals, academic talks, and other presentations.

## What it does

- Plans the presentation’s structure and gives each slide a clear purpose.
- Selects layouts, typography, colors, imagery, and visual elements that work together.
- Uses icons and diagrams to explain processes, categories, and relationships.
- Chooses charts according to the data and keeps units, time periods, and sources clear.
- Adds animation when it helps the audience follow an explanation.
- Checks readability, consistency, template leftovers, and the promised level of editability.

## How to use

Place the `i-canhandle-this` folder in your Codex Skills directory, then include `$i-canhandle-this` in your request. For example:

> Use `$i-canhandle-this` to create an editable presentation about conducting mental-health screening at a university. Choose appropriate layouts, icons, charts, and animation based on the content.

The original template collection is **not required** to use this skill. The package includes design guidance and a small set of editable sample pages. Replace all sample content before publishing, verify rights for any reused images, and review the final presentation before use.
